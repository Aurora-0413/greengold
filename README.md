# 一、核心叙事线（建议首页滚动讲述）

用一句话概括：**“从卖石头 → 卖风景 → 美丽经济”**。把时间线对准三个关键节点：

1. **关矿止损**：2003—2005 年，余村陆续关停 3 座矿山与 1 家水泥厂，集体收入一度从约 300 万元降至 20 万元，但换来了生态修复的起点。([证券时报][1])
2. **理念诞生**：2005 年 8 月 15 日，**习近平（汉语：习近平，罗马音：Xí Jìnpíng，1953年6月15日生）**在余村提出“绿水青山就是金山银山”。可在页面做“语音+题词石碑”联动亮点。([新华网][2])
3. **蝶变为证**：2021 年余村入选联合国世界旅游组织“最佳旅游乡村”；2024 年余村年接待游客约 115 万人次、旅游收入超 5580 万元；安吉县域 2024 年全县游客 3402.1 万人次、旅游总收入 475.6 亿元。([中国日报][3])

> 技术点子：在这些节点处触发“前后对比（英语：**before–after image slider**）”、“数字从 0 跳变的计数器”、以及地图定位动画，细节一到位，故事就“活”了呀～🌿

# 二、页面模块设计（Vue3 友好）

**技术栈建议**：Vue3 + Vite；可视化用 **Apache ECharts（英语：Apache ECharts）**；地图用 **Mapbox GL JS（英语：Mapbox GL JS）** 或高德的 Web SDK；叙事滚动用 **scrollytelling（英语：scrollytelling）** 组合库（如 GSAP/ScrollTrigger）；数据静态放 JSON/CSV 即可，首屏懒加载以保性能～

1. **首屏｜一眼余村**
   全屏视频或 360 图（题词石碑+溪流），叠加一句“从矿山到绿野，从尘霾到清风”的 Slogan，小字标注理念出处与年份。([新华网][2])

2. **滚动叙事｜时间线**
   横向时间尺：2003 关停矿山 → 2005 理论提出 → 2010s 生态修复 → 2021 “最佳旅游乡村”。每一格弹出“照片/小数据/村民故事卡片”。（村民口述可引用公开报道摘要与摄影展照，注意版权～）([证券时报][1])

3. **数据驾驶舱｜绿色发展指标**

   * 生态：水质达标率、森林（或植被）覆盖、PM2.5/PM10 趋势；
   * 经济：游客量、旅游收入、村集体/人均收入、绿色产业占比；
   * 社会：青年返乡创业数、合作社数量。
     可做折线图+桑基图（英语：**Sankey diagram**）展示“产业结构从采矿→文旅/新农业”的迁移；安吉县域总量数据放在旁侧作参照。([中国新闻网][4])

4. **地图｜走读余村**
   “一矿、一河、一片林”三段式路线：旧矿坑改造点→溪流廊道→竹海步道。每到一站弹出“修复前后”影像与指标（如 COD、氨氮、植被盖度的对比小卡片），再配上 10 秒自然声场按钮（鸟鸣、溪水）增沉浸感哟～

5. **案例微观察｜理念扩散**
   小地图标注“‘两山’理念”在浙江乃至全国的若干实践点，点击可读 1～2 段“怎么做、做成啥”。（保持客观、中性表述与出处指引）

6. **互动区｜我的绿色账本**
   迷你“碳足迹估算（英语：**carbon footprint**）”表单：一次校内往返、一次点外卖、一次共享出行的近似碳排；给出“等效种树”与“低碳替代”建议，最后生成一张可分享的小海报 (*canvas 导出*)。

7. **参考与致谢**
   把关键事实的来源附在页尾：理念提出时间、关停矿山年份、游客与收入数据、UNWTO 名录等，确保可追溯。([新华网][2])

# 三、数据与素材怎么找（可落地）

* **理念与时间线**：新华社 15 周年稿、外交部/权威媒体余村条目。([新华网][2])
* **关矿细节与转型故事**：证券时报人物报道、环球时报专题。([证券时报][1])
* **荣誉与近年文旅数据**：CGTN/新华社“最佳旅游乡村”，中国日报余村游客量与收入（2024），中国新闻网安吉县域 2024 年总量。([中国日报][3])

> 小贴士：若拿不到长期序列，就做“对比年”卡片（如 2005 vs 2021/2024），同样能讲清“趋势感”。

# 五、视觉与交互小心思

* **色彩**：竹绿（#2E7D32）为主，辅以“金山”灵感的暖金（#CDA434）作高亮；
* **版式**：留白充足，卡片圆角与阴影轻一点；
* **动效**：滚动渐显 + 关键数字“跳数”；地图标注采用“呼吸光圈”；
* **可达性**：深浅色切换、图表加 alt 描述、小屏适配；
* **性能**：首屏控制在 < 1.5MB，图片用 WebP + 懒加载，第三方库分包。

# 六、两种落地路径

* **MVP（1～2 天）**：首屏 + 时间线 4 节点 + 2 张关键图（游客量/收入）+ 地图 3 标注 + 参考资料页。
* **展陈版（进阶）**：加声音博物馆、碳账本、前后对比滑块、数据驾驶舱与“理念扩散”地图，适配大屏展示与移动端。
